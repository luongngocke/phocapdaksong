Hệ thống Đối chiếu Dữ liệu Phổ cập Giáo dục - Đắk Song

Công cụ hỗ trợ rà soát, so sánh chéo giữa bảng dữ liệu Dân cư (Phổ cập) và Cơ sở dữ liệu ngành Giáo dục. Giúp giáo viên nhanh chóng lọc ra danh sách học sinh cần đi điều tra thực tế. Mọi dữ liệu đều được xử lý cục bộ trên trình duyệt, an toàn và bảo mật.

Hướng dẫn các bước thực hiện:
  1. Tải lên file Excel/CSV chứa Dữ liệu dân cư/phổ cập và file chứa Dữ liệu ngành.
  2. Xác nhận dòng tiêu đề (mặc định là dòng 1).
  3. Lựa chọn các cột tương ứng (Họ tên, CCCD) để hệ thống biết cách so sánh (Ưu tiên dò bằng CCCD).
  4. Bấm "Thực hiện đối chiếu" và chờ kết quả. Chuyển sang các Tab bên dưới để xem hoặc xuất Excel.
